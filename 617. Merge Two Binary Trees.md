### Step1

反復の方が書きやすそう。
元のノードと新たなノードをペアにして、ループを回せばいいか。
新たなノードを割り当てるための if文でネストが深くなってしまった。
一回のループで同時に、２つの木の値を足していくよりも簡単になると思う。

BFSを選択した。
```python
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root1:
            return root2
        if not root2:
            return root1

        new_root = TreeNode()
        for root in [root1, root2]:
            nodes_with_new = deque([(root, new_root)])
            while nodes_with_new:
                node, new_node = nodes_with_new.popleft()
                new_node.val += node.val
                if node.left:
                    if not new_node.left:
                        new_node.left = TreeNode()
                    nodes_with_new.append((node.left, new_node.left))
                if node.right:
                    if not new_node.right:
                        new_node.right = TreeNode()
                    nodes_with_new.append((node.right, new_node.right))
        return new_root

```

## Step2

他の人のコードを読もう。
感想：
- 元のノードと新たなノードの位置関係が、一階層ずれたような書き方もある
- その場合はダミーが必要になるか
- コードの量は減りそうだけど、少し複雑になってしまう
- 再帰の深さについて再確認
	- https://stackoverflow.com/questions/3323001/what-is-the-maximum-recursion-depth-and-how-to-increase-it
- 前の問題みたいに、再帰処理をスタックに翻訳している
- 再帰 <--> スタックの関係はこの練習会でよく見る
- `filter(None, iterable)` 初めて見た


DFS stack で書いた。
補助関数がないと見た目が悪くなる。

```python
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        def merge(node1, node2):
            if not node1 and not node2:
                return None
            val = 0
            if node1:
                val += node1.val
            if node2:
                val += node2.val
            return TreeNode(val=val)

        root = merge(root1, root2)
        stack = [(root1, root2, root)]
        while stack:
            node1, node2, new_node = stack.pop()
            if not node1 and not node2:
                continue
            if not node1:
                node1 = TreeNode()
            if not node2:
                node2 = TreeNode()
            new_node.left = merge(node1.left, node2.left)
            new_node.right = merge(node1.right, node2.right)
            stack.append((node1.left, node2.left, new_node.left))
            stack.append((node1.right, node2.right, new_node.right))
        return root

```

### Step3

- 再帰が書きやすい
- 返り値を変更したら入力が壊れる可能性があるので、 `deepcopy` を使う

```python
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        # if not root1 and not root2:
        #     return None
        if not root1:
            return copy.deepcopy(root2)
        if not root2:
            return copy.deepcopy(root1)
        root = TreeNode(val=root1.val+root2.val)
        root.left = self.mergeTrees(root1.left, root2.left)
        root.right = self.mergeTrees(root1.right , root2.right)
        return root

```
