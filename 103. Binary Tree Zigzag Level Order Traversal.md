### Step1

- 前回の問題とほぼ同じ
- カウントして偶数だったら左から右、奇数だったら右から左
- ひとまず通常のlevel order traversal をして、`values` を `result` に入れるときに反転させるか決めればいいだけ

```python
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        result = []
        level = 0
        nodes = [root]
        while nodes:
            if (level % 2 == 0):
                result.append([node.val for node in nodes])
            else:
                result.append([node.val for node in nodes[::-1]])
            next_nodes = []
            for node in nodes:
                if node.left:
                    next_nodes.append(node.left)
                if node.right:
                    next_nodes.append(node.right)
            nodes = next_nodes
            level += 1
        return result
        
```

### Step2

- カウントして奇数か偶数かで判断するよりも、フラグを使う方がわかりやすい
- 自分は次の層ことを考えるよりも前に、先にノードの値を処理しておきたいことがわかった
- `values` をdequeとする方法は思いつかなかった

dequeを使って実装してみる。

```python
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []

        left_to_right = True
        result = []
        nodes = [root]
        while nodes:
            values = deque()
            next_nodes = []
            for node in nodes:
                if left_to_right:
                    values.append(node.val)
                else:
                    values.appendleft(node.val)
                if node.left:
                    next_nodes.append(node.left)
                if node.right:
                    next_nodes.append(node.right)
            result.append(list(values))
            left_to_right = not left_to_right
            nodes = next_nodes
        return result
      
        
```
