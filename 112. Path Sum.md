### Step1

- DFS でパスを辿っていく
- 入力の大きさから、再帰の高さについて注意する必要がある
- スタックを使うのもあり
- 再帰で書くなら、何を引数として渡すか

- パスの途中でターゲットサムと等しくなったら返していたが、これは勘違いだった
- root-to-leaf の全体の値を考えるべきだった
- 実際のインタビューでも緊張しすぎて、こういう間違いしそう

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], target_sum: int) -> bool:
        def has_path_sum(node, sum_so_far):
            if not node:
                return False
            sum_so_far += node.val
            if not node.left and not node.right:
                return sum_so_far == target_sum
            return has_path_sum(node.left, sum_so_far) or \
                   has_path_sum(node.right, sum_so_far)
        
        return has_path_sum(root, 0)

```

### Step2

- Step1では、`num_so_far`を選択したが、再帰で呼び出した時点では`previous_sum`とした方が適切だった
- `path_sum` という変数名がいい: https://github.com/ryosuketc/leetcode_arai60/pull/25
- 同じような解法が多かった

スタックで書いた。
node が None でもスタックに入れることはできるが、葉ノードに辿り着くたびに２つの空ノードを入れたくない。

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], target_sum: int) -> bool:
        if not root:
            return False
        nodes_and_path_sum = [(root, root.val)]
        while nodes_and_path_sum:
            node, path_sum = nodes_and_path_sum.pop()
            if not node.left and not node.right:
                if path_sum == target_sum:
                    return True
            if node.left:
                nodes_and_path_sum.append((node.left, path_sum + node.left.val))
            if node.right:
                nodes_and_path_sum.append((node.right, path_sum + node.right.val))
        return False
            
```

### Step3

再帰はこのコードがしっくりくる。
スタックの解法でも良かった。

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], target_sum: int) -> bool:
        def has_path_sum(node, previous_sum):
            if not node:
                return False
            path_sum = node.val + previous_sum
            if not node.left and not node.right:
                return path_sum == target_sum
            return has_path_sum(node.left, path_sum) or \
                   has_path_sum(node.right, path_sum)
        
        return has_path_sum(root, 0)

```
