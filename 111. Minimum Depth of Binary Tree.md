### Step1

- 再帰と反復の解き方がある
- 反復の方が書きやすそう
	- 子がないノード（leaf node）を見つけたら、その地点での深さを返す
- 再帰のベースケースは、root が存在しない場合と、leaf node の場合の２つがある

反復：
```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        min_depth = 1
        nodes = [root]
        while nodes:
            next_nodes = []
            for node in nodes:
                if not node.left and not node.right:
                    return min_depth
                if node.left:
                    next_nodes.append(node.left)
                if node.right:
                    next_nodes.append(node.right)
            min_depth += 1
            nodes = next_nodes
        return min_depth
```

再帰：
```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        if not root.left and not root.right:
            return 1
        left_height = self.minDepth(root.left) if root.left else math.inf
        right_height  = self.minDepth(root.right) if root.right else math.inf
        return 1 + min(left_height, right_height)
```

### Step2

他の人のコードを読む。

感想：
- 再帰で `math.inf` を使わなくてもいい書き方がある
- 急に `math.inf` が出てきたら驚くので、避けた方が良さそう
- スタックを使った DFS のような解法もある
- DFS だとノード全てを探索するが、BFS はルートから最短の葉を見つけた時点で終了するからより直感的


色々な書き方を試してみたい。
DFS の処理を、スタックを使って書いてみよう。
ノードが `None` の場合でも、スタックに追加して、取り出した時に無視する書き方もできる。

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
            
        min_depth = math.inf
        nodes_with_depth = [(root, 1)]
        while nodes_with_depth:
            node, depth = nodes_with_depth.pop()
            if not node.left and not node.right:
                min_depth = min(min_depth, depth)
            if node.left:
                nodes_with_depth.append((node.left, depth + 1))
            if node.right:
                nodes_with_depth.append((node.right, depth + 1))
        return min_depth
```

`math.inf` を使わない再帰：

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        if not root.left and not root.right:
            return 1
        if not root.left:
            return 1 + self.minDepth(root.right)
        if not root.right:
            return 1 + self.minDepth(root.left)
        return 1 + min(self.minDepth(root.left), self.minDepth(root.right))
```


### Step3

- この問題の場合は、BFS が直感的で好きだった。

最終的なコード:

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        min_depth = 1
        nodes = [root]
        while nodes:
            next_nodes = []
            for node in nodes:
                if not node.left and not node.right:
                    return min_depth
                if node.left:
                    next_nodes.append(node.left)
                if node.right:
                    next_nodes.append(node.right)
            nodes = next_nodes
            min_depth += 1
        assert False  # Should not reach here

```
