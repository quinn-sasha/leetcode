## Step1

* 問題の解法は思いついたが、コードにするのが難しかった。まだ頭の中の動きを機械に伝える訓練が足りていないことと、単純にプログラミング言語にそこまで慣れてない。
* preorder_index をインクリメントしていけば、preorder順に木を作ることになる
	* preorder は木を作ったりコピーするときに使うということを本で読んだ気がする
	* inorder 単体だと木を特定することができない 
	* inorder = [1, 2, 3] の場合、2か1どちらもルートになる可能性がある。
	* inorder と preorder もしくは postorder との組み合わせが必要
* preorder で取得したルートのinorderでの位置がわかると、左と右にどれくらいの子がいるかがわかる
子の数という情報がわかれば、再帰の終了条件にできる

```cpp
#include <unordered_map>


class Solution {
   std::unordered_map<int, int> val_to_inorder_pos_;
   int preorder_index_ = 0;


   TreeNode* buildTreeHelper(vector<int>& preorder, int left, int right) {
       if (left > right) {
           return nullptr;
       }
       if (left == right) {
           return new TreeNode{preorder[preorder_index_++]};
       }
       TreeNode* root = new TreeNode{preorder[preorder_index_++]};
       int index = val_to_inorder_pos_[root->val];
       root->left = buildTreeHelper(preorder, left, index - 1);
       root->right = buildTreeHelper(preorder, index + 1, right);
       return root;
   }


public:
   TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
       for (int i = 0; i < inorder.size(); i++) {
           val_to_inorder_pos_[inorder[i]] = i;
       }
       return buildTreeHelper(preorder, 0, preorder.size() - 1);
   }
};
```

## Step2

* 他の人の解法を3つぐらい見たが、この問題では解答の幅が小さい気がした
* inorderの要素数が1になった時に早期リターンするかどうか悩んだ

```cpp
class Solution {
   int preorder_index_ = 0;
   std::map<int, int> val_to_inorder_pos_;


   TreeNode* bulidTreeHelper(vector<int>& preorder, int left, int right) {
       if (left > right) {
           return nullptr;
       }
       TreeNode* root = new TreeNode{preorder[preorder_index_]};
       preorder_index_++;
       int split_index = val_to_inorder_pos_[root->val];
       root->left = bulidTreeHelper(preorder, left, split_index - 1);
       root->right = bulidTreeHelper(preorder, split_index + 1, right);
       return root;
   }


public:
   TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
       for (int i = 0; i < inorder.size(); i++) {
           val_to_inorder_pos_[inorder[i]] = i;
       }
       return bulidTreeHelper(preorder, 0, inorder.size() - 1);
   }
};
```
