### Step1

- BFS を使うパターン
- リストにグループとしてまとめるのは同じ層のノードか
- 帰り値にそのままノードを突っ込んでいた
- よく問題を確かめる
- 他の解法は思いつかなかった

```python
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []

        result = []
        nodes = [root]
        while nodes:
            result.append([node.val for node in nodes])
            next_nodes = []
            for node in nodes:
                if node.left:
                    next_nodes.append(node.left)
                if node.right:
                    next_nodes.append(node.right)
            nodes = next_nodes
        return result
        
```

### Step2

- 深さを利用して、どの層にいるか見分ける方法
- Step1の方が好き
- 今いるレベルを見て、次の層をまとめるリストが挿入する処理が少し難しい

```python
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        
        result = []
        nodes_and_levels = deque([(root, 0)])
        while nodes_and_levels:
            node, level = nodes_and_levels.popleft()
            if level >= len(result):
                result.append([])
            result[level].append(node.val)
            if node.left:
                nodes_and_levels.append((node.left, level + 1))
            if node.right:
                nodes_and_levels.append((node.right, level + 1))
        return result
        
```
