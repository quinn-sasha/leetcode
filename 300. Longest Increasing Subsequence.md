30分くらい考えてわからなかったので、neetcode で解法を見た。
まずは Broute-force での解法が無駄に計算している箇所を特定して、その無駄な計算を回避するために、DPの解法を導き出していた。
Broute-force からより効率的な解法を導き出すためには、絵を描く必要があると思った。
時間計算量は、 O(N^2) になる。最大で N = 2500 なので、ステップ数は大体 2.5^2 * 10^6 で、C++の場合1秒間に実行できるステップ数を 10^8 とすると、実行時間は 60 ms ぐらい。

### Step2

map を使う解法を知った。
時間計算量は O(N^2 log N) になる。
今までに見た数字 -> 長さ をmapに記録している。新たに見た数字と今までに見た数字を比較して、新しい数字の方が大きければ、長さを1増やす。
map を使わなくても、vector で実装できる。

O(N log N) の解法を見たが、これを初見で思いつくのは難しそう。まずは O(N^2) の解法を導き出せるようになろう。


確かに lengthes という変数名だと何を保持しているのか伝わらない。
「i より左側にある lis_length の内、nums[i] より小さいLISの長さを探す」という関数に切り出す選択いいなと思った。
https://github.com/hayashi-ay/leetcode/blob/hayashi-ay-patch-16/300.%20Longest%20Increasing%20Subsequence.md

step1 と step2 のアプローチは似ているが、管理している lis_lengthes と lengthes の値の意味が異なっていた。
step1 の場合、lengthes[i] は nums[i] を数列の始点とした際の LIS の長さを保持している。
一方で step2 では、lis_lengthes[i] は nums[i] を数列の終端とした時の LIS の長さを指している。
例として 0, 1, 0 という数列を考えた時、index = 0 であれば lengthes[i] = 2, lis_lengthes[i] = 1 となり、index = 2 のケースでは lengthes[i] = 1, lis_lengthes[i] = 1 という結果になる。

### Step1

* Broute-Force（30分かかった）

```cpp
class Solution {
    int lengthOfLISHelper(vector<int>& subsequence, 
                          int index, 
                          const vector<int>& nums) {
        if (index >= nums.size()) {
            return subsequence.size();
        }
        if (!subsequence.empty() && subsequence.back() >= nums[index]) {
            return lengthOfLISHelper(subsequence, index + 1, nums);
        }
        auto added = subsequence;
        added.push_back(nums[index]);
        return std::max(
            lengthOfLISHelper(subsequence, index + 1, nums),
            lengthOfLISHelper(added, index + 1, nums)
        );
    }

public:
    int lengthOfLIS(vector<int>& nums) {
        std::vector<int> subsequence;
        return lengthOfLISHelper(subsequence, 0, nums);
    }
};
```

* Dynamic Programming 解法（8分）

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        std::vector<int> lengthes(nums.size(), 1);
        int max_length = 1;
        for (int i = nums.size() - 1; i >= 0; --i) {
            for (int j = i + 1; j < nums.size(); ++j) {
                if (nums[i] < nums[j]) {
                    lengthes[i] = std::max(lengthes[i], 1 + lengthes[j]);
                    max_length = std::max(max_length, lengthes[i]);
                }
            }
        }
        return max_length;
    }
};
```

class Solution {
    int find_max_length_below_limit(int end, int limit, 
                                    const std::vector<int>& nums,
                                    const std::vector<int>& lis_lengthes) {
        int max_lis_length = 0;
        for (int i = 0; i < end; ++i) {
            if (nums[i] < limit) {
                max_lis_length = std::max(max_lis_length, lis_lengthes[i]);
            }
        }
        return max_lis_length;
    }

public:
    int lengthOfLIS(vector<int>& nums) {
        // nums[i]をsubsequenceの末尾にした時の、LISの長さ
        std::vector<int> lis_lengthes(nums.size(), 1);
        int max_length = 1;
        for (int i = 1; i < nums.size(); ++i) {
            lis_lengthes[i] = 1 + find_max_length_below_limit(
                i, nums[i], nums, lis_lengthes
            );
            max_length = std::max(max_length, lis_lengthes[i]);
        }
        return max_length;
    }
};
