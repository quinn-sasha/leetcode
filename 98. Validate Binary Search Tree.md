### Step1

親の位置から左右の子の値を見ていく。
最大ノード数は10^4(10000)なので、もし木が片方に傾いている場合は再帰の上限を超えるかもしれない。
rootは空にならないらしいけど、例外処理しようかな。
単純に親と子の関係だけではないことに気づく。
ここで詰まったので解法をみる。

木の下を見ていたが、木の上を見るべきだった。

```python
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def is_valid(node, smaller, bigger):
            if not node:
                return True
            if not (node.val > smaller and node.val < bigger):
                return False
            return (is_valid(node.left, smaller, node.val) and
                    is_valid(node.right, node.val, bigger))
        
        return is_valid(root, -math.inf, math.inf)

```
### Step2

- math.infはfloatで、比べているnode.valと異なることは気にしとくべきだった
- inorder traversal で昇順になっているか調べる方法もある
- nonlocalは、ローカル変数を１つ上のスコープに位上げする（知らなかった）
- `lower`, `upper` という変数名がいい

Inorder traversal をするとノードの値がソートされているはず。
知識として知っていたけど、この問題に応用することは思いつかなかった。

```python
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        smaller_node_val = -math.inf
        def is_valid_bst(node):
            if not node:
                return True
            nonlocal smaller_node_val
            if not is_valid_bst(node.left):
                return False
            if node.val <= smaller_node_val:
                return False
            smaller_node_val = node.val
            return is_valid_bst(node.right)
        return is_valid_bst(root)
        
```

### Step3

- DFSの解法に落ち着いた
- スタックの方が個人的には好きだった
- 正直空のノードがvalidな気がしないので、空のノードが来るとエラーが起こるようにした

```python
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        stack = [(root, -math.inf, math.inf)]
        while stack:
            node, lower, upper = stack.pop()
            if not (lower < node.val < upper):
                return False
            if node.left:
                stack.append((node.left, lower, node.val))
            if node.right:
                stack.append((node.right, node.val, upper))
        return True
       
```
