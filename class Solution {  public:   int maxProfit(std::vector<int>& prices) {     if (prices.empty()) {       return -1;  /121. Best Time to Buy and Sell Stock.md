## Step1

最終日に買っても、売ることはできない。
まずは2重ループのナイーブな解法を思いつた。
各prices[i]を買う日とした場合、その日以降を全て見て最大の利益をそれぞれ見つけるという解法。
この解法だと 10^10 / 10^8 = 100秒でめっちゃ時間がかかってしまう。
元の解法の無駄な点は、同じ日が複数回売る日として計算されていること。
この無駄を省くには、prices[i]で売った時の最大の利益を計算する。
* 初日に売ることはできないので、利益は0。
* 二日目は初日に買うしかない。
* 三日目は初日か二日目の内安い方で買う。

つまり毎日売ることを考えながら、一番安く買える日があったらメモをとって、profit = prices[i] - 一番安い値段 で最大の利益を更新していく。

時間計算量はO(N) (N: prices.length = 10^5) なので、大まかな実行時間 = 10^5 / 10^8 = 1ms.
