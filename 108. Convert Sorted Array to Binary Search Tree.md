### Step1

- キーポイントは、既にソートされいてるということ
- 直感的には、配列の真ん中の要素を根にすればよさそう
- もしくは、AVL tree みたいに rebalance() を実装するか、でもこれは求められていない気がする
- 再帰で書けそう
- 二分探索みたい
- ヘルパー関数の命名が難しい

```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        def array_to_bst(nums, left, right):
            if left >= right:
                return None
            mid = left + len(nums[left:right]) // 2
            node = TreeNode(val=nums[mid])
            node.left = array_to_bst(nums, left, mid)
            node.right = array_to_bst(nums, mid + 1, right)
            return node
        
        return array_to_bst(nums, 0, len(nums))
```

### Step2

- `left`, `right`, `mid` のうち `mid` だけ省略するのは違和感を感じるのだろうか
	- 今回の問題の場合、スコープの範囲は狭いから許容範囲か
- `nums` が空の場合、IndexError になることに気づかなかった
- `(left + right) // 2` で書くと短くなるが、 `left + (right - left) // 2` の方が直感的だと思った

BFS で実装した。

```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None

        root = TreeNode()
        nodes_with_range = deque([(root, 0, len(nums))])
        while nodes_with_range:
            node, left, right = nodes_with_range.popleft()
            mid = (left + right) // 2
            node.val = nums[mid]
            if left < mid:
                node.left = TreeNode()
                nodes_with_range.append((node.left, left, mid))
            if mid + 1 < right:
                node.right = TreeNode()
                nodes_with_range.append((node.right, mid + 1, right))
        return root
```

class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        def sorted_array_to_bst(left, right):
            if left >= right:
                return None
            mid = (left + right) // 2
            node = TreeNode(val=nums[mid])
            node.left = sorted_array_to_bst(left, mid)
            node.right = sorted_array_to_bst(mid + 1, right)
            return node 
        return sorted_array_to_bst(0, len(nums))
